# Origin and licensing

The initial release of KithCore and Meadow Sample was generated with **Codex**, using a mix of **GPT-6.1 Sol** and **GPT-6.1 Astra**, under human direction. This includes code, documentation, game text, procedural art recipes, interface assets and build tooling. This is a release-level disclosure, not a file-by-file model attribution. Later contributions may have different origins; contributors should describe significant generated material and external sources in their pull requests.

These projects explore a **social-first MMORPG sandbox**: persistent shared worlds, conversation, social interaction and developer-authored content that can evolve while players remain connected. They are experimental alpha software. Supported live updates use existing engine mechanics and art; arbitrary code, geometry and new mechanics require maintenance. No model service is needed to run a game.
