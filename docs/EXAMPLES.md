# Example worlds

**Meadow Sample** (`worlds/minimal/`) is the included, editable example and the default world in the engine download. Use its small definitions, [market-day bundle](../worlds/minimal/examples/live-update.json) and campaign tests when learning the engine. It runs independently of any other world.

**Emberwild** is a second, independently distributed example with a more complete starting zone, city content, geography, story and procedural asset library. It requires the base engine to run. Its world-only archive installs into a compatible engine; its starter archive includes a tested pair. It is a sandbox under development, not a finished MMO.

The intended repositories are [KithCore](https://github.com/jspjut/kithcore) and [Emberwild](https://github.com/jspjut/emberwild), with [engine downloads](https://github.com/jspjut/kithcore/releases) and [world/starter downloads](https://github.com/jspjut/emberwild/releases). The engine's site configuration defaults to the Emberwild repository link; `EMBERWILD_REPOSITORY=owner/repository` overrides it for forks. See [build and Pages setup](BUILD_AND_PAGES.md), [packaging](RELEASING.md) and the world's README. Verify these destinations after publication.
